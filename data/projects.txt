description - A computer game based on the Mastermind board game. I attempted this project in the past, however, due to an error in the project which myself and even AI agents couldn't solve, I quit it prematurely. Despite this, I decided to try again but made sure to create numerous error checks and exceptions to prevent a situation similar to my first attempt. This project uses an Object-Oriented programming paradigm for the components of the project: board, round and game. Whilst the core gameplay loop is simple, the complexity of the project comes from the various features which allow for fully customisable rounds/games to be played by the user.
